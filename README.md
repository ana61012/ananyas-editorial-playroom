# Ananya's Studio Press

Create a modern, visually polished portfolio website for **Ananya Singh**, a graphic designer.

### Overall Creative Direction

The website should feel like a **playful editorial design studio / creative portfolio** — artistic, youthful, sophisticated, and slightly quirky without becoming childish.

The visual identity should take subtle inspiration from the type of work Ananya has created, especially:

* A **Crockey catalogue** — use the feeling of product catalogues, editorial layouts, typography, grids, product photography, and clean compositions.
* A **dog wedding poster** — bring in a small amount of playful personality, charming illustrations/details, and unexpected visual elements.

Do NOT make the website look like a generic corporate portfolio or an overly futuristic "tech designer" website.

### Color Palette

Use a warm, sophisticated palette inspired by print/editorial design:

* Warm ivory / off-white background
* Deep chocolate brown
* Muted burgundy or wine
* Soft peach / dusty pink as an accent
* Small touches of muted green if needed

Keep the colors restrained. The website should look like a beautifully designed printed catalogue translated into a modern website.

### Typography

Use a combination of:

* A distinctive editorial serif font for large headings
* A clean modern sans-serif for body text and navigation

Large typography should be an important part of the visual identity.

Use interesting typography treatments such as:

* Oversized headings
* Italic serif accents
* Small uppercase labels
* Editorial-style captions
* Generous whitespace

### Navigation

Create a minimal sticky navigation bar:

**ANANYA SINGH**
Work / About / Contact

Keep navigation simple and elegant.

## INTERACTIONS & ANIMATION

Keep animations elegant and subtle.

Use:

* Smooth scrolling
* Image reveal animations
* Gentle hover zoom on project images
* Typography appearing on scroll
* Slight movement on decorative elements
* Cursor interaction on project thumbnails
* Smooth page transitions

Do NOT use excessive:

* neon gradients
* glassmorphism
* 3D effects
* glowing UI
* particle backgrounds
* complicated animations

The work itself should remain the focus.

### Important Design Requirement

The portfolio should feel like **a graphic designer designed their own website**, not like a developer generated a template.

Prioritize:
**typography + composition + whitespace + imagery + editorial layout**

over excessive UI components.

Make the site fully responsive for desktop, tablet and mobile.

Use high-quality image placeholders for the Crockey catalogue and dog wedding poster, but structure the website so I can easily replace them with my actual project images later.

The final result should feel like a **small independent creative studio portfolio**: warm, memorable, sophisticated, playful, and visually cohesive.
