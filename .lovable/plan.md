# Ananya Singh Portfolio

## Goal
Build a warm, editorial graphic-design portfolio that feels like a small independent studio: refined, playful, image-led, and easy to update.

## Pages and structure
- Create a sticky minimal navigation with Work, About, and Contact.
- Build the homepage with the requested oversized introduction, asymmetric selected-work layout, future-project tiles, about copy, design principles, skills, bold contact area, and minimal footer.
- Add dedicated case-study pages for Crockey and The Dog Wedding, each with project overview, objective, type and color notes, large image sequences, mockups, and outcome.
- Keep all project artwork references and copy organized so real images can be swapped in later.

## Visual direction
- Use warm ivory, chocolate, burgundy, dusty peach, and restrained muted green through semantic design tokens.
- Pair an expressive editorial serif with a clean sans-serif; use oversized titles, italic accents, captions, rules, and generous whitespace.
- Use asymmetric catalogue-inspired compositions with subtle hand-drawn dog, paw, stamp, and star details.
- Generate cohesive high-quality placeholder artwork for the catalogue, poster, project spreads, and portrait.

## Interaction and responsiveness
- Add smooth scrolling, restrained reveal motion, gentle image zoom, tactile project-thumbnail cursor feedback, and subtle decorative movement.
- Respect reduced-motion preferences.
- Adapt compositions deliberately for desktop, tablet, and mobile without losing the editorial hierarchy.

## Technical details
- Use TanStack routes for the homepage and both shareable case studies.
- Define the design system in the global Tailwind v4 stylesheet and load editorial fonts through document head links.
- Add unique metadata for every page and preserve a single semantic H1 per page.
- Verify the completed site in desktop and mobile browser sizes, including navigation and project links.
